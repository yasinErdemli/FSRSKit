# Notices

## fsrs-rs

FSRSKit is a Swift port of FSRS-7 from [fsrs-rs](https://github.com/open-spaced-repetition/fsrs-rs),
the reference implementation of FSRS, at commit
[`0a57374`](https://github.com/open-spaced-repetition/fsrs-rs/tree/0a5737406a0c5c7a5259b144738cbe4a0b649d76)
(9 October 2026): the memory model, the interval solver, parameter clipping,
the scheduling penalties, the optimizer and the evaluation metrics, with their
constants and default parameters.
